# Research 
- Licenses fall into 2 main categories: 
	- Permissive -> allow users to use, modify and distribute software/hardware without maintaining the original license original license
	- Copyleft -> require that any derivative works be distributed under the same license, ensuring that the software remains open and freely available
		- Weak -> This only requires that the source code of the original or modified work is made publicly available, while the rest of the code used together with the work doesn't have to be published under the same license.
		- Strong -> If a source code is protected by a strong copyleft license, then the derivative software needs to be publicly available under that license as well. This includes all linked libraries and components within the software.

# Commonly used Licenses 

## GPL (General Public License)

### [GPL-2.0](https://opensource.org/license/gpl-2-0) 
- This is a strong copyleft open source software license released in 1991
#### Rules
- any modifications or derivatives of GPLv2-licensed code must also be released under the same license to ensure the code remains open source.
- Any modifications made to the code must be released under the GPLv2 license if distributed.
- When distributing compiled binaries, the complete corresponding source code must be made available, or a written offer to provide the source code must be given.
- The license prohibits sublicensing under different terms, meaning all publicly distributed modifications must be licensed under GPLv2.
- Users are permitted to use GPLv2-licensed code commercially, modify it, and distribute it, including in commercial software, as long as the source code of the modified version is made available under the same license. 
	- However, if the code is used internally within a company and not distributed to others, modifications do not need to be shared.
